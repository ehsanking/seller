# SELLER Storefront — Vue 3 + Tailwind CSS

An enterprise-ready Vue 3 composition API storefront for **SELLER Core (ehsanking/seller)**.

## Key Features
- Vue 3 Pinia state management for cart & user sessions
- Instant search and filtering powered by SELLER Headless REST API
- Fully styled with Tailwind CSS

## Quick Start
```bash
cd storefronts/vue-tailwind
npm install
npm run dev
```
